Gjennomgående perspektiv

Security begynner ikke i siste modul

Security er både et eget pensumområde og en rød tråd gjennom resten av emnet. User/kernel separation beskytter kernel, process isolation skiller programmer, memory protection og virtual memory begrenser tilgang, og system calls gir kontrollerte innganger til privilegerte operasjoner.

Fra teori til system

Concept → mechanism → implementation → practical use

Faget knytter sammen hva et problem er, hvordan OS-et løser det, hvordan løsningen implementeres og hvordan mekanismen brukes i praksis.

  1. ConceptHva er problemet eller abstraksjonen?
  2. MechanismHvordan kontrollerer eller fordeler OS-et ressursen?
  3. ImplementationHvilke data structures, interfaces og hardwaremekanismer brukes?
  4. Practical useHvordan observeres, programmeres og debugges dette i et virkelig system?

Praktisk systemprogrammering går på tvers

Arbeidsområdet omfatter Unix/Linux og command line, små programmer i C og/eller Rust, compilation og debugging, samt arbeid med memory, processes, threads, system calls og synchronization. Grunnleggende x86/x64-arkitektur brukes som forkunnskap der det er relevant.
