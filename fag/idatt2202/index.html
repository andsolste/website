Kort emneoversikt

Hva faget dekker

Faget handler om kernel og system calls, processes og threads, concurrency og synchronisation, scheduling, virtual memory, caching, file systems, security og low-level/system programming.

Arbeidsform: Undervisningen bruker flipped classroom. Kunnskapsmodulen og Canvas-quizen gjennomføres før forelesningen, slik at tiden sammen kan brukes til utdyping og anvendelse.

Hovedpensum

Operating Systems: Principles and Practice, 2nd edition
Thomas Anderson & Michael Dahlin

Security-modulen
Operating Systems and Middleware, Chapter 11
Max Hailperin
