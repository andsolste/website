Språk og kjøremiljø

JavaScript i moderne webutvikling

JavaScript er programmeringsspråket for interaktive websider. Det brukes i dag til store webapplikasjoner og single page applications, ikke bare små effekter på en dokumentbasert side.

1995
JavaScript ble utviklet for Netscape.
ECMAScript
Språket ble standardisert slik at implementasjoner kunne følge en felles spesifikasjon.
DOM
Standardisering ga plattformuavhengig tilgang til websiders dokumentstruktur.
Node.js · 2009
En runtime som gjorde JavaScript viktig også utenfor browseren.
Skill mellom språk og runtime: JavaScript er språket. Browseren og Node.js er forskjellige miljøer som kan kjøre JavaScript.

En bevisst trade-off

JavaScript som dynamisk typet språk

I JavaScript bestemmes typen ved runtime ut fra verdien. Den samme variabelen kan derfor referere til verdier av forskjellige typer mens programmet kjører.

let value = 10;
value = "ti";

Fordeler

Fleksibelt og lett å komme i gang med

  • enklere språk
  • raskere koding
  • mindre kode
  • høy fleksibilitet

Ulemper

Mindre kan kontrolleres før kjøring

  • typefeil kan oppdages sent
  • mindre statisk kvalitetssikring
  • kan bli vanskeligere i større programvareprosjekter

Dynamisk typing er ikke i seg selv dårlig. Den gir fleksibilitet, men flytter mer ansvar til runtime og utvikleren.

Kode som kan organiseres og gjenbrukes

Moduler og moderne syntaks

Import og export

Modularisering deler et stort prosjekt i mindre filer med tydelig ansvar. Det gjør koden enklere å vedlikeholde, organisere og gjenbruke.

Eksporter fra en modul

export const double = (x) => x * 2;

export gjør en verdi eller funksjon tilgjengelig utenfor modulen.

Importer i en annen modul

import { double } from "./math";

import henter noe som en annen modul eksporterer.

Denne strukturen blir viktig i React-prosjekter med mange filer og komponenter.

Arrow functions

Arrow functions er en kompakt funksjonssyntaks som brukes mye i moderne JavaScript, særlig til korte funksjoner, callbacks og array-metoder.

Vanlig funksjon

function double(x) {
    return x * 2;
}

Arrow function

const double = (x) => {
    return x * 2;
};

const compactDouble = x => x * 2;

Den samme syntaksen dukker senere opp i React-komponenter og event handlers. Her er poenget å kunne lese og skrive funksjonsformen, ikke å gå inn i avansert this-semantikk.

Object destructuring

Destructuring henter felt fra et objekt på en kompakt måte.

const user = {
    name: "Andreas",
    id: 1
};

const { name, id } = user;

Dette er en kort bro til syntaks som brukes mye i senere React-kode.

Typekontroll under utvikling

TypeScript fra kildekode til browser

TypeScript er et open-source programmeringsspråk utviklet av Microsoft. Det er et syntaktisk superset av JavaScript som legger til valgfri statisk typing.

JavaScript og TypeScript

JavaScript

Språket som kjører

  • dynamisk typing
  • typer avgjøres ved runtime
  • fleksibelt
  • browserens runtime-språk

TypeScript

Et typet lag i utviklingssteget

  • statisk typekontroll under utvikling
  • type annotations og interfaces
  • bedre tooling og tidligere oppdagelse av typeproblemer
  • transpileres til JavaScript

Fra enkeltverdier til datastrukturer

Typer og datastrukturer

Type inference og eksplisitte typer

TypeScript kan ofte finne typen automatisk fra verdien. Det kalles type inference.

let foo = "Dette er en test";
// TypeScript infererer foo som string

let bar: string = "test";

function add(a: number, b: number): number {
    return a + b;
}

I funksjonen er a og b parametertyper, mens den siste number-annotasjonen er returtypen.

Grunntyper

string · number · bigint · boolean · undefined · null · symbol

Dette er en kompakt oversikt over typene som ble introdusert, ikke en full TypeScript-reference.

Interfaces og type aliases

Begge formene under beskriver strukturen data forventes å ha. På dette nivået er poenget å kunne type et dataobjekt, ikke å gå dypt inn i forskjellene mellom interface og type.

Interface

interface User {
    name: string;
    id: number;
}

Type alias

type User = {
    name: string;
    id: number;
};
Data object→type / interface→forventet struktur er kjent

Union types, literal types og tuples

Union og literal

let age: number | string;

age = 18;
age = "18";

type AgeGroup = "barn" | "ungdom" | "voksen";
let group: AgeGroup = "barn";

En union tillater én av flere eksplisitt angitte typer. En literal type begrenser verdien til konkrete alternativer.

Tuple

let user: [string, number] = ["Andreas", 20];

En tuple er en array-lignende struktur med fast rekkefølge og bestemte typer per posisjon.

any

let value: any = 18;
value = "atten";

any betyr i praksis at TypeScript slutter å hjelpe med mye av typekontrollen for denne verdien. Det kan være nyttig i spesielle situasjoner, men overdreven bruk reduserer fordelene med TypeScript.

Data gjennom funksjoner

Funksjonell programmering

Funksjonell programmering er et programmeringsparadigme der oppgaven uttrykkes som evaluering av funksjoner. Stilen legger vekt på immutable values, funksjoner som parametre og en deklarativ beskrivelse av hva som skal gjøres fremfor hvert enkelt steg.

Funksjonell transformasjon

Nye data produseres

input→pure function→new output

Mutasjon

Originaldata endres

input→mutate original data

Denne programmeringsstilen har blitt sentral igjen i moderne JavaScript og danner et viktig grunnlag for måten React-kode senere organiseres på.

Forutsigbare transformasjoner

Immutability, pure functions og side effects

const array1 = [1, 4, 9, 16];
const array2 = array1.map((x) => x * 2);

array1 forblir uendret. array2 inneholder de nye, transformerte verdiene. I stedet for å endre eksisterende data produseres nye data.

Pure function

Samme input gir samme output

  • endrer ikke data utenfor eget scope
  • gir samme output for samme input
  • er lettere å forstå og teste

Side effect

Påvirker noe utenfor resultatet

  • endrer global state
  • skriver til noe utenfor funksjonen
  • muterer input
  • påvirker systemtilstand

Immutability reduserer uforutsigbare side effects ved å gjøre transformasjonen fra input til ny output tydelig.

Callbacks og datatransformasjon

Array-metoder og function chaining

Metodene under er sentrale fordi de uttrykker valg, transformasjon og aggregering med funksjoner. Målet er å forstå rollen deres, ikke å memorere en full API-reference.

map()
const doubled = numbers.map(x => x * 2);

Returnerer en ny array med transformerte verdier.

filter()
const even = numbers.filter(x => x % 2 === 0);

Returnerer en ny array med verdiene som matcher betingelsen.

find()
const firstLarge = numbers.find(x => x > 10);

Returnerer den første verdien som matcher.

some()
const hasLarge = numbers.some(x => x > 10);

Returnerer en boolean som sier om minst én verdi matcher.

every()
const allPositive = numbers.every(x => x > 0);

Returnerer en boolean som sier om alle verdiene matcher.

reduce()
const sum = numbers.reduce((total, x) => total + x, 0);

Kombinerer mange verdier til én verdi.

Function chaining

const result = numbers
    .filter(x => x > 0)
    .map(x => x * 2);
  1. filter velger de relevante verdiene.
  2. map transformerer dem.
  3. Den opprinnelige arrayen forblir uendret.

Hva fremfor hvert steg

Deklarativ og imperativ stil

Imperativ

const output = [];

for (let i = 0; i < numbers.length; i++) {
    output.push(numbers[i] * 2);
}

Fokuserer på hvordan operasjonen utføres steg for steg.

Deklarativ

const output = numbers.map(x => x * 2);

Fokuserer på hva transformasjonen skal produsere.

Imperativ kode er ikke alltid dårlig. Ved datatransformasjoner kan funksjonell og deklarativ stil likevel gi kortere og mer lesbar kode.

Rask repetisjon

Kortversjonen

  • JavaScript gir webapplikasjoner dynamisk oppførsel.
  • Dynamisk typing betyr at typen bestemmes ved runtime ut fra verdien.
  • TypeScript er et superset av JavaScript med statisk typekontroll.
  • Transpilation gjør TypeScript om til JavaScript som browseren kan kjøre.
  • Type inference lar TypeScript finne typen automatisk.
  • Interfaces og type aliases beskriver strukturen på data.
  • Union types tillater flere eksplisitt definerte typer.
  • any slår i praksis av mye av typekontrollen.
  • import og export brukes til modularisering.
  • Arrow functions brukes mye i moderne JavaScript.
  • Funksjonell programmering favoriserer immutable data og pure functions.
  • Array-metodene map, filter, reduce, find, some og every bruker callbacks til databehandling.
  • Deklarativ kode beskriver ofte hva vi ønsker fremfor hvert enkelt steg.
  • React bygger videre på dette programmeringsgrunnlaget.
